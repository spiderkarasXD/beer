# Shifr & Games

Веб-сервис для шифрования текста в секретный код и обратно + набор браузерных мини-игр.

---

## Основные функции

- **Шифратор:** перевод текста (русский / английский) в секретный код и расшифровка обратно.
- **Material 3:** светлая и тёмная тема, адаптив под телефон и ПК.
- **Игры → Аркада:** Сапёр, Змейка, Флаги (угадай страну), Кликер с сохранением прогресса и оффлайн-доходом.
- **Игры → Удача:** мини-игры на виртуальные очки (Плинко, Ракетка, Барабаны, Колесо). Реальных денег нет, всё хранится в браузере.
- **Разделы → Rice:** калькулятор риса и переводчик из риса в метры, литры, стады Roblox, юниты CS2, вольты, скорость и т.д.
- **Копирование в один клик.**

## Технологический стек

- **Frontend:** HTML5, CSS3 (Material 3), чистый JavaScript без фреймворков.
- Нейтральная версия сайта — в папке `es/`.

## Как пользоваться

1. Откройте сайт.
2. Введите текст в левое поле.
3. В правом поле сразу появится результат.
4. Нажмите **«Копировать»**.
5. Загляните в раздел **«Игры»**.
