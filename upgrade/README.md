# UPGRADER — симулятор апгрейда скинов CS2

Виртуальная валюта зарабатывается кликами, реальных денег нет.

- **Скины** — все скины CS2 с картинками из [ByMykel/CSGO-API](https://github.com/ByMykel/CSGO-API) (лежат в `catalog.json`).
- **Цены** — реальные, с публичного API [Skinport](https://docs.skinport.com/) в USD.
- **База** — Supabase: аккаунты, баланс, инвентарь, лидерборд, онлайн и лента апгрейдов в реальном времени.
- **Никаких секретных ключей в репозитории.** Во фронтенде только публичный ключ Supabase. Цены обновляет Edge Function, которой Supabase сам передаёт секретный ключ.

## Быстрый старт

Сайт полностью статический: папку целиком можно залить на GitHub Pages, Vercel, Netlify или Cloudflare Pages. На beerlanguage.ru он открывается как раздел `/upgrade/`.

Локально, на Node 18+, зависимостей нет:

```bash
npm start
```

После запуска сайт открыт на http://localhost:3000.

Если в `config.js` не указан Supabase, сайт работает в локальном режиме. Прогресс тогда хранится в браузере, а локальный сервер отдаёт свежие цены через `/api/catalog`.

## Подключение своего Supabase

1. Создайте проект на https://supabase.com.
2. **SQL Editor → New query**: вставьте `supabase/schema.sql` и нажмите **Run**. Повторный запуск безопасен: так же обновляется схема.
3. **Authentication → Sign In / Providers → Email**: выключите **Confirm email**, чтобы игроки входили сразу.
4. **Edge Functions → Deploy a new function → Via Editor**:
   - имя: `sync-prices`;
   - код: вставьте `supabase/functions/sync-prices/index.ts` целиком;
   - нажмите **Deploy**;
   - в настройках функции выключите **Verify JWT** (Enforce JWT Verification). Сайт вызывает функцию с публичным ключом.

   Или через CLI (настройка `verify_jwt = false` уже лежит в `supabase/config.toml`):
   ```bash
   npx supabase functions deploy sync-prices --project-ref <ref>
   ```
5. В `config.js` впишите `Project URL` и ключ **Publishable** (Project Settings → API Keys).

Всё. При первом заходе сайт сам вызовет `sync-prices`, и через 10–20 секунд цены появятся в базе. Потом сайт обновляет их, если они старше 15 минут. Чаще одного раза в 10 минут функция обновлять не даёт, даже если её дёргают много раз.

### Необязательно: обновление цен по расписанию

Пригодится, если цены должны быть свежими, даже когда на сайт никто не заходит. Включите расширения **pg_cron** и **pg_net** (Database → Extensions) и выполните:

```sql
select cron.schedule('sync-prices', '*/15 * * * *', $$
  select net.http_post(
    url := 'https://<ref>.supabase.co/functions/v1/sync-prices',
    headers := '{"Content-Type": "application/json"}'::jsonb
  );
$$);
```

## Как устроено

| Что | Где |
|---|---|
| Вёрстка | `index.html`, `styles.css` |
| Логика: апгрейд, кликер, инвентарь, лента, лидерборд | `app.js` |
| Названия, картинки, снимок цен | `catalog.json` (пересборка: `npm run build:catalog`) |
| Обновление цен в базе | `supabase/functions/sync-prices/index.ts` |
| Таблицы, защита (RLS), серверные функции | `supabase/schema.sql` |
| Локальный сервер (необязателен) | `server.mjs` |

**Защита от накрутки.** Клиент не может напрямую менять баланс или инвентарь. Всё идёт через функции в Postgres:

- `register_clicks`: не больше 20 кликов в секунду, $0.01 за клик.
- `do_upgrade`: шанс и бросок считаются на сервере по ценам из таблицы `items`.
- `sell_items`: продаёт по текущей цене.

Записывать в `items` может только Edge Function.

**Цены.** Берётся медиана реальных продаж на Skinport за 30 дней, а если продаж меньше трёх — за 90 дней. Если продаж не было, используется медиана выставленных лотов, но только когда лотов хотя бы 3: одиночный лот может стоить сколько угодно. У Doppler берётся самая дешёвая фаза.

**Валюта.** В базе всё хранится в долларах. На экране суммы показаны в рублях по живому курсу USD→RUB с open.er-api.com, курс кэшируется на 6 часов. Клик даёт $0.01, это около 0,8 ₽. В магазине (вкладка Shop) скины кладутся в корзину. По значку корзины открывается список: там можно убрать лишнее и купить за баланс через `buy_items`.

**Быстрый выбор.** Кнопки x2/x4/x8 подбирают цель в N раз дороже входа, а 35%/55%/75% — цель с таким шансом. Значения настраиваются в Settings (шестерёнка) и сохраняются в браузере.

**Разработка.** Если открыть сайт с параметром `?local` (`http://localhost:3000/?local`), он работает в локальном режиме, даже когда Supabase прописан в config.js.

**Правила апгрейда.** Шанс = (предметы + баланс) / цена цели × 0.95. Допустимый диапазон — от 1% до 75%. Константы продублированы в начале `app.js` и в `schema.sql`. Если меняете их, меняйте в обоих местах.

**Новые скины.** Когда в CS2 выходят новые скины, выполните `npm run build:catalog` и закоммитьте обновлённый `catalog.json`.
